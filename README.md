# Dirt Legends — Motocross & ATV mod (Fabric, Minecraft 1.21.1)

Dirt bikes, ATVs, track building and lap racing, inspired by MX vs ATV, in a blocky vanilla style.

## What's in it

**Vehicles** (4 colours each: red, blue, green, yellow)
- **Dirt Bike**: fast and light. Leans into turns and pops wheelies off the line. Top speed about 68 km/h.
- **ATV**: slower but more stable. Can reverse properly, and the body rolls outward in turns. Top speed about 58 km/h.

**How they ride**
- Steering works like a real bike: tight turns when slow, wide turns when fast.
- **Traction depends on the ground:**
  - Track Dirt is fastest.
  - Dirt and grass grip well.
  - Sand and gravel bog you down and slide.
  - Mud and soul sand are slow.
  - Snow is sketchy, and ice is a skating rink.
  - Water nearly stalls you.
- **5-speed gearbox:** the engine sound revs up and drops on every shift. A HUD next to the hotbar shows km/h, the gear and an RPM bar.
- **Jumps:** hit a ramp or hill fast and you'll get air. **Kicker Ramps** launch you properly. Hold **Space** to preload the suspension and release it to pop (the jump bar).
- **In the air:** **W** pushes the nose down, **S** pulls it up, and **A/D** scrubs sideways. Land level, because landing more than about 40° nose-high or nose-down **crashes** you.
- Slamming into a wall at speed also crashes you. A crash throws you off and hurts.
- The suspension squashes on landings, and dirt sprays off the back tyre.

**Motocross gear**: Helmet, Jersey, Pants and Boots. Wearing **all four** cuts crash and hard-landing damage by 70%.

**Track blocks**
| Block | What it does |
|---|---|
| Track Dirt | The fastest, grippiest surface |
| Dirt Ramp / Dirt Slab | Build jumps, berms and rhythm sections |
| Kicker Ramp | Wooden launch ramp. It rises toward the way you face when you place it |
| Start/Finish Line | Starts the lap timer, then times every lap and tracks your best |
| Checkpoint | Place at least one around the track; a lap only counts if you pass one |

**Controls**
- Right-click the ground with a vehicle item to place it.
- Right-click the vehicle to get on. **Shift** gets off.
- **W** is throttle. **S** brakes, then reverses (bikes only shuffle backwards).
- **A/D** steer.
- Punch the vehicle to pick it back up.

All items are in the **Dirt Legends** creative tab, and everything has a crafting recipe. The vehicles need an **Engine** (iron, redstone, piston) and **Knobby Tires** (dried kelp and an iron nugget).

## Turning this into a mod you can play

This folder is the mod's **source code**. It has to be built into a `.jar` file once. Pick one way:

### Option A: on your PC (easiest)
1. Install **Java 21**, for example "Temurin 21" from adoptium.net.
2. Open a terminal / command prompt in this folder.
3. Run `gradlew build` (Windows) or `./gradlew build` (Mac/Linux).
   - The first build downloads Minecraft and Fabric, so it takes a few minutes.
4. Your mod is at `build/libs/dirt-legends-1.0.0.jar`. Ignore the `-sources` jar.

Or open the folder in **IntelliJ IDEA Community**, wait for it to load, then in the Gradle panel run **Tasks → build → build**.

### Option B: let GitHub build it
Upload this folder to a new GitHub repository. The included workflow builds it automatically. Go to **Actions → latest run → Artifacts** to download the jar.

### Install it
1. Install the **Fabric Loader** for Minecraft **1.21.1** from fabricmc.net/use.
2. Put the built jar **and** the **Fabric API** mod (for 1.21.1, from Modrinth or CurseForge) into your `.minecraft/mods` folder.
3. Launch the Fabric 1.21.1 profile.

To test it straight from the source code, run `gradlew runClient`.

## Tweaking
- **Handling** (top speed, acceleration, steering, lean): `src/main/java/com/dirtlegends/entity/VehicleStats.java`
- **Grip per surface:** `entity/Surface.java`
- **Models, textures, sound and recipes** are generated by `tools/gen.py` (needs Python with Pillow, numpy and ffmpeg). Change the shapes or colours there and re-run `python3 tools/gen.py .`
